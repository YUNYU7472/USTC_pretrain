## 使用说明（先看）

1. **视频是入口，不是通关证据**。每项只有在「能口头解释、纸上推导、关视频手写、测试通过」后才能勾选。
2. 每日顺序建议：**视频/教材 30–50 分钟 → 数学与笔记 25–35 分钟 → 手写代码 60–90 分钟 → 自测 15–25 分钟**。论文复杂时只读当天指定图表/章节。
3. 本文的 **「B站直达」** 采用检索核实过的具体视频/合集网址；同一合集反复引用时，**每天的「观看定位」不同**。**「B站检索」** 只是搜索入口，不能保证其中某个视频可靠或仍在线。并非每个小众气象模型都有适合入门的中文视频，这时**以原论文、官方文档和开源仓库为主**。
4. 一律先用小型随机张量完成 forward/backward 测试，再连接真实气象数据；模型复现仅做到**核心教学模块**，不要求两个月内重训完整 Pangu、GraphCast、ClimaX。
5. 气象数据使用 [WeatherBench 2 64×32 ERA5](https://weatherbench2.readthedocs.io/en/latest/data-guide.html) 起步；先读取短时间切片，**不要盲目下载整个全球高分辨率仓库**。该数据既有训练监督目标，也可用于教学预报；**它不等价于原始卫星、地面站观测**。
6. 严禁数据泄漏：标准化只拟合训练集；训练/验证/测试按时间划分；异步融合只使用预测发布时刻真实可用的观测（不仅检查观测发生时间，也检查到达/可用时间）。
7. 每天打卡顺序：**基础四项（保留原版）→ 细化实践 → 验收标准**；周末复盘时检查 `.py/.ipynb/.md`、Git commit 和图表。每日必做优先于选做的搜索视频。
